# react-native-hilal

Hijri (Umm al-Qura) and Gregorian date picker for React Native. Cross-platform, Expo Go ready, zero dependencies.

## Installation

```sh
npm install react-native-hilal
```

## Usage

```js
import { multiply } from 'react-native-hilal';

// ...

const result = multiply(3, 7);
```
