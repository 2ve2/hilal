# Security policy

## Supported versions

Security fixes go into the latest release only. Update to the latest version of `react-native-hilal` before reporting.

## Reporting a vulnerability

Please don't open a public issue for a security problem. Report it privately instead:

- with **Report a vulnerability** on the repository's [Security tab](https://github.com/2ve2/hilal/security), or
- by message to [@lord2ve](https://t.me/lord2ve) on Telegram.

Describe the problem, the affected versions and, if you can, how to reproduce it. Once a fix is released, the report can be credited in the release notes if you want.

Hilal runs no network requests, stores nothing and has no runtime dependencies, so most reports will be about wrong dates or crashes. Those are bugs rather than security issues and are welcome as normal [issues](https://github.com/2ve2/hilal/issues).
